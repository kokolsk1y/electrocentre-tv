# Управление эфиром через Telegram

## Правила показа

- Очередь состоит из баннеров, роликов и существующих встроенных сцен. Порядок каждого объекта задаёт сотрудник. Программа не чередует и не повторяет объекты автоматически.
- У баннера есть название акции, место в очереди, дата и время начала, а также плановая дата окончания. Ролики по умолчанию бессрочны; их место в очереди можно менять.
- Плановая дата окончания служит напоминанием о замене. Без запланированной замены баннер остаётся в эфире и помечается как просроченный. Снять его может только явное действие сотрудника.
- Будущая замена занимает то же место в очереди в назначенное время. Исправление действующего баннера заменяет его изображение и сохраняет выбранный период.
- Телевизор применяет новую очередь или замену после завершения текущего объекта. Поэтому фактический переход может задержаться на время текущего ролика.

## Работа сотрудника

1. Открыть в боте пронумерованный список с названиями, миниатюрами, сроками и статусами.
2. Подготовить черновик: добавить баннер, назначить замену, исправить изображение, изменить сроки, передвинуть любой объект или снять его.
3. Открыть ссылку предпросмотра на отдельной странице Worker. HTML берётся из ветки разработки в GitHub, медиа — с GitHub Pages. Любой, у кого есть ссылка, видит только черновик; ссылка не даёт права изменять его.
4. Нажать «Опубликовать». Все изменения черновика становятся действующими вместе. Запланированные замены затем срабатывают в назначенное время.

## Техническая схема

- GitHub Pages продолжает отдавать рабочую TV-страницу и медиа; отдельную демонстрационную страницу отдаёт Worker.
- Cloudflare Worker принимает команды Telegram, отдаёт опубликованную очередь и данные черновика по отдельной ссылке.
- Cloudflare D1 хранит опубликованную редакцию, черновик, сроки, порядок и состояние операций.
- Cloudflare R2 хранит изображения баннеров. Новый файл проверяется до публикации. Старый удаляется после переключения эфира и безопасной задержки. Отмена черновика также удаляет неиспользуемые загруженные изображения.
- Токен Telegram хранится в секретах Cloudflare. Команды изменения доступны только разрешённым Telegram ID. Ссылка предпросмотра содержит отдельный случайный токен только для чтения.

## Проверка перед запуском

- Перенести текущий порядок всех объектов без потери роликов, баннеров и встроенных сцен.
- Проверить показ при нуле баннеров, двух роликах подряд, замене текущего баннера, будущей замене и просроченном баннере без замены.
- Проверить, что черновик не меняет действующий эфир, а публикация переключает весь набор сразу.
- Проверить обновление на Samsung Smart TV и совместимость с существующим режимом объявления заказов.

## Что понадобится для запуска

- Токен нового Telegram-бота и Telegram ID сотрудников, которым разрешено редактирование.
- Доступ к аккаунту Cloudflare для Worker, D1 и R2.
- Доступ для публикации изменений репозитория на GitHub Pages.

Текущие локальные изменения проекта сохраняются. Перед коммитом и публикацией нужно включить только файлы этой функции и проверить diff.
