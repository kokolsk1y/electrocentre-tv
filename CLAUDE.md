## Правила работы
- Актуальная версия всегда `electrocentre-tv-v2.1.html` — редактировать её
- Не создавать новые версии (v14, v2.2 и т.д.) — только редактировать текущий файл
- Картинки для новых баннеров класть в `slides/MM.YYYY/` (помесячные папки) с ASCII-именами файлов (без пробелов и кириллицы)
- **Формат картинок — WebP, не PNG.** Все новые баннеры конвертировать: quality=90, max width 1920px, method=6 (через Pillow). Typical экономия 95–98% vs PNG без видимой потери качества
- После изменений — коммитить на GitHub (Pages обновится автоматически)

### Скрипт конвертации PNG → WebP
```python
from PIL import Image
img = Image.open('src.png').convert('RGBA')
if img.width > 1920:
    h = round(img.height * 1920 / img.width)
    img = img.resize((1920, h), Image.LANCZOS)
if img.mode == 'RGBA':
    bg = Image.new('RGB', img.size, (255,255,255))
    bg.paste(img, mask=img.split()[3]); img = bg
img.save('dst.webp', 'webp', quality=90, method=6)
```
